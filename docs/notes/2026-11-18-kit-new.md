# kit-new: Preview pane (and the Theme row's top screen), Section rail, Book bar, Away mark, Screen-off warning

The five "new" components of docs/redesign/components.md, built on branch `kit-new` (beside `kit-variants`, which
builds the variants: kept in new files so the two merge cleanly). How a kit component is written:
2026-11-16-redesign-kit.md.

- **`Ui::KitNew`** is a struct nested in `Ui` (so it may use Ui's private drawing), declared at the end of

## The Preview pane on the top panel

- `Ui::topPane(PaneSpec&)` says which pane (none: false); `SettingsPage::topPane` gives the Theme row's.
  `TopScreen::draw` asks it every pass, but composes (`composePane`, ~22 ms at 1280x960 on a Mac) only when the
  spec's key plus the theme's id or the panel's size changes, and draws it 1:1 through its own `PageRenderer`, as About's
  support QR is drawn. Nothing else is drawn while it is up: mpv isn't rendered.
- **Only while nothing plays**: not with a video, a song (paused too) or a photo loaded, nor with a reader open or the
  QR up. The spec: while something plays the top screen is the picture.
- **Its ground is the theme's BG** (Light, 16-bit and 32-bit are light there), unlike the idle logo screen, which the
  themes work kept black. Its "Over a video · Cards stay dark" card is drawn in TOP_ tokens.
- Dropped (the row left, something started): its texture freed, `topDark` cleared so mpv's idle picture is drawn again.
- Log: `top: preview pane up theme-row|yellow 640x480 in N ms`, `... now ...` on each change, `top: preview pane
  dropped`. A top panel stuck on the pane shows as an "up" with no "dropped".
- **A level card (volume, brightness) is not seen while the pane is up**: it is an mpv overlay and mpv isn't drawn. The
  QR has the same gap. If it matters, draw the card into the pane's renderer as `cardOnReader` does for the readers.

## What differs from the spec, and why

- **Swatches** follow the drawing (screens.js `thSwatch`): BG, a SURFACE box with its own edge, ACCENT, a TEXT line,
  an ACCENT line; the chosen one's edge ACCENT and a unit wider, its name ACCENT too.
- **Book bar** is drawn into a target texture and turned with `SDL_RenderCopyEx` (90° top screen left, 270° right: the
  manga reader's convention). A renderer without target textures gets it unturned at the foot (logged once:
  `kit: no target texture for the Book bar`). It draws its own hint bar inside the sheet. 339 tall ("about 340").
- **Screen-off warning**: only the drawing. The timer has no five-second warning today, the "Dim before turning off"
  setting doesn't exist, and the backlight drop to a third is behaviour: wiring it is a feature of its own (Ui::tick's
  screen-off block, the setting, a key or touch that only cancels). Not a drop-in, so not used. On the top screen the
  spec's note at the foot is the existing note card (`drawNoteCard` with G_MOON and `screenOffWords`).
- **Away mark**: the helper and the dot. The header badge is left to the variants branch (it builds the badges); the
  gallery shows the dot on a chip and on a lit key, and pills for the words.
- **Section rail**: not a drop-in for `drawSectionHeader` (the shell's layout changes around it), so unused.
- Fonts: no new `F_*` sizes (the other branch may add some: FONT_DEFS would conflict). The rail's label is F_I11B
  (11, the spec 11.5), the warning's count F_P14 (the spec 15).
